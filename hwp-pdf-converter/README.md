# HWP to PDF Converter

윈도우 데스크톱에서 실행 가능한 HWP/HWPX 파일을 PDF로 변환하는 프로그램입니다.

## 주요 기능

- HWP, HWPX 파일을 PDF로 변환
- 여러 파일 동시 변환 (일괄 처리)
- 폴더 단위 파일 추가 지원
- 파일 용량 제한 없음
- 저장 폴더 지정 가능
- 실시간 변환 진행 상황 표시
- EXE 파일로 배포 가능

## 시스템 요구사항

- Windows 10/11
- **한컴오피스(한글) 설치 필수** (무료 뷰어는 불가)
- Python 3.8 이상 (개발/빌드 시)

## 설치 및 실행

### 방법 1: EXE 파일 실행 (권장)

1. `dist` 폴더의 `HWP-PDF-Converter.exe` 파일 실행
2. 또는 아래 방법으로 직접 빌드

### 방법 2: 소스에서 빌드

```batch
# 1. 저장소 클론 또는 다운로드

# 2. build.bat 실행
build.bat

# 3. dist 폴더에 생성된 EXE 실행
```

### 방법 3: Python에서 직접 실행

```batch
# 의존성 설치
pip install -r requirements.txt

# 실행
python main.py
```

## 사용 방법

1. **파일 추가**
   - "파일 추가" 버튼으로 HWP/HWPX 파일 선택
   - "폴더 추가" 버튼으로 폴더 내 모든 HWP 파일 추가
   - 드래그 앤 드롭으로도 추가 가능

2. **저장 위치 설정**
   - 기본값: 원본 파일과 같은 폴더에 저장
   - "폴더 선택" 버튼으로 저장 위치 변경 가능

3. **변환 시작**
   - "PDF로 변환 시작" 버튼 클릭
   - 진행 상황과 결과가 실시간으로 표시됨

## 프로젝트 구조

```
hwp-pdf-converter/
├── main.py              # GUI 메인 애플리케이션
├── converter.py         # HWP→PDF 변환 로직 (COM 인터페이스)
├── requirements.txt     # Python 의존성
├── build.bat           # EXE 빌드 스크립트
├── HWP-PDF-Converter.spec  # PyInstaller 설정
└── README.md           # 사용 설명서
```

## 기술 상세

- **GUI**: Python tkinter (표준 라이브러리)
- **HWP 처리**: 한컴오피스 COM 인터페이스 (pywin32)
- **패키징**: PyInstaller

## 주의사항

1. **한컴오피스 설치 필수**: 이 프로그램은 한컴오피스의 COM 인터페이스를 사용합니다. 한글 뷰어나 한컴독스로는 작동하지 않습니다.

2. **변환 중 한글 프로그램 사용 불가**: 변환 중에는 한글 프로그램이 백그라운드에서 실행됩니다.

3. **암호화된 문서**: 암호가 걸린 HWP 파일은 변환되지 않을 수 있습니다.

## 문제 해결

### "한컴오피스가 설치되어 있지 않습니다" 오류

- 한컴오피스(한글 2020 이상 권장)를 설치하세요
- 설치 후에도 오류가 발생하면 한글을 한 번 실행한 후 다시 시도하세요

### "Class not registered" 오류

- 한글 프로그램을 관리자 권한으로 한 번 실행하세요
- 그래도 안 되면 한컴오피스를 재설치하세요

### 변환 실패

- 파일이 손상되지 않았는지 확인하세요
- 파일에 암호가 걸려있지 않은지 확인하세요
- 한글 프로그램에서 직접 열어보세요
